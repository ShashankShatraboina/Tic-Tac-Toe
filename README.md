# Multiplayer Tic Tac Toe

Multiplayer Tic Tac Toe is an interactive game application where two players can play Tic Tac Toe together in real time. The project focuses on smooth gameplay, responsive design, and an enjoyable multiplayer experience.

## Features
- Two-player multiplayer gameplay
- Real-time game board updates
- Interactive and responsive interface
- Win, lose, and draw detection
- Lightweight and easy to use

## Technologies Used

- HTML, CSS, JavaScript

## How It Works
Players take turns marking X and O on the game board. The game automatically checks for winning combinations, draws, and updates the results in real time.
